### Binary Search Tree
Istilah penting:

leaf: node tanpa anak
height: jumlah level dari root ke leaf terdalam

## Recursive
Setiap fungsi rekursif harus punya:

Base case: kondisi berhenti, jawaban yang sudah pasti tanpa memanggil diri sendiri.

Recursive case: pemanggilan diri sendiri dengan masalah yang lebih kecil, bergerak menuju base case.
